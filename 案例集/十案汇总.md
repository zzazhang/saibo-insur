## 二、三组受控对比

三组均为同一事故、同一套损失参数，仅变更一项变量，差额可干净归因。

### A. C1 vs C6 — 外包商责任（安联 vs 平安 B 款）

| | 计入金额 | 赔付额 | 赔付率 |
| --- | ---: | ---: | ---: |
| C1 安联 | 5,939,910 | 5,789,910 | 97.5% |
| C6 平安 B 款 | 5,707,200 | 2,438,360 | 41.1% |

**差额 3,351,550 元。** 主因排序（这个顺序很重要，容易归因错）：

1. **第三方责任（占差额主体）** — 平安 B 款以第一方为主，法律与调查费用分项限额仅 50 万，削减 1,888,000 元
2. 检测与专业机构费用限额 30 万，削减 830,240 元
3. 数据恢复与安全防御限额 50 万，削减 440,600 元
4. 外包商相关条款 — S1-02 依赖中断除外、F1-06 供应链调查降为有限承保

若把差额笼统归因于「外包商责任」，结论对但理由错。为使外包商除外真正咬合，
C1 案情必须显式包含 F1-06 供应链调查费与 S1-02 依赖中断损失——
若只用普通科目，平安 B 款的外包商除外一次都不会触发。

**悬崖提示**：平安 B 款第十五条第十三款除外的是「IT 外包商**未被认可**的操作失误」。
本案设定运维商已在保单明细表中列为认可服务提供商。若企业更换运维供应商后未书面
通知保险人（国内极常见），该条构成**原因型除外，整案赔付归零**。

### B. C7 vs C9 — 第一方与第三方互补（同一保险人）

| | 计入金额 | 赔付额 | 赔付率 |
| --- | ---: | ---: | ---: |
| C7 国寿财 B 款 | 2,855,178 | 2,705,178 | 23.3% |
| C9 国寿财 责任险 | 8,360,000 | 8,260,000 | 71.2% |

**重叠承保科目 0 项。** 两款产品承保范围完全不相交，一分钱不重复。

| 采购组合 | 赔付 | 覆盖事实损失 |
| --- | ---: | ---: |
| 只投 B 款 | 2,705,178 | 23.3% |
| 只投责任险 | 8,260,000 | 71.2% |
| **两款合投** | 10,965,178 | **94.5%** |

只投 B 款则 836 万第三方索赔裸奔，只投责任险则 285 万自身损失裸奔。
仍有 39 万元（加固费 + PLC 硬件）两边都不赔——**缺口不因多买一张保单而消失**。

**最大不确定性**：下游主机厂索赔依据的是供货协议交付违约条款，性质更接近合同责任。
多数责任险对纯合同违约设有除外。若核赔认定为违约金，C9 的 800 万全部落空。

### C. C8 vs C8B — 赎金反事实

| | 事实损失 | 计入金额 | 赔付额 | 赔付率 |
| --- | ---: | ---: | ---: | ---: |
| C8 未付赎金 | 2,695,838 | 1,246,838 | 1,040,000 | 38.6% |
| C8B 已付 60 万 | 3,295,838 | 1,246,838 | 1,040,000 | 31.6% |

**多损失 60 万，赔付额一分不变。** 中远海运第八条第一款明文承保赎金、第十二条设了
独立分项限额、第二十六条索赔材料里直接写了「勒索金支付记录」——文本上配置完整。
但第二十三条要求「涉及网络勒索须立即向公安部门报案」，索赔时须**同时**提交报案回执
与支付记录。这两份材料在国内难以同时合法取得，**条款自己把自己堵死了**。

## 三、四类结构性发现

### 1. 「名义承保」是一类现象，不是赎金的孤例

| 责任项 | 条款限定语 | 保单 |
| --- | --- | --- |
| 赎金 | 「按照中国法律规定」 | 国寿财 B 款 |
| 赎金 | 「在中国法律允许范围内」 | 多款 |
| 赎金 | 须报案 + 须提交支付记录（互斥） | 中远海运 |
| **行政罚款** | 「**在法律和赔偿支付地允许承保的前提下**」 | 安达 |

安达的行政罚款条款与赎金条款是**同一种句式**。国际条款移植入境时保留了本国不可
执行的责任项，靠一句限定语把风险推回投保人。这使「名义承保」从单点观察升级为
可命名的模式。

### 2. 框架缺口两处，且性质不同

| | C2 行政罚款 | C3 资金本金 |
| --- | --- | --- |
| 条款态度 | 写了，但国内不可赔 | 写了，且可赔 |
| 69 科目 | 无对应位置 | 无对应位置 |
| 漏掉的后果 | 低估**真实损失** | 低估**赔付额** |
| 本案处理 | 文字记录 + 量化落差 | 借用 F1-10 并标注 |
| **建议增设** | **R1-07 行政罚款与监管处罚**（默认 nominal_only） | **S2-06 资金损失（被骗或被盗资金）** |

C2 的量化后果：表面赔付率 98.7%，计入罚款后真实覆盖率 75.2%，**落差 23.6 个百分点**；
工具显示自留 12 万，实际自留 312 万，**差 26 倍**。

两个缺口都指向同一结论：本土化损失分类框架需要在国际条款结构之外增设科目。

### 3. 三个坑在真实案例中的实际金额

**坑① 等待期与免赔额重复扣减** — higher_of 已三次适用，**取值方向三次不同**：

| 案例 | 等待期自留 | 免赔额 | 取值 |
| --- | ---: | ---: | --- |
| C7 国寿财 B | 160,500 | 150,000 | 等待期 |
| C3 苏黎世 | 47,938 | 200,000 | 免赔额 |
| C4 泰康 | 153,920 | 100,000 | 等待期 |

不能简化为固定做法。C4 若按错误做法多扣 10 万，而该金额已接近该案营业中断
可赔基数的两倍——**坑①在中小额中断中破坏力最大**。

**坑② 分项限额是否占用累计限额** — 苏黎世 5.2.3/5.3.3–5.3.7、安联明细表第六项、
国寿财 B 款 13.1 节均明确「不额外增加」；中远海运第七条的安全服务包则独立于现金
赔付限额。同样叫「分项限额」，两种结构结果不同。

**坑③ 免赔额适用范围与条件免赔额** — 中远海运第四条「隐患未整改免赔额上浮 10%」
（C8 实测多扣 1 万）；珠峰第五条第七款「非指定机构全额免赔」（C10 实测赔付归零）。

**坑④ 保单参数漏进事实层** — S3-01 赎金分项限额、F8-01 品牌修复限额是行内公式
变量，填了会让核定损失记成限额而非实际发生额。指定保单后重复设限即告警。

### 4. 三条实务发现

**SLA 补偿与保险赔付高度重叠（C4）**。营业中断毛损失 487,311 → 扣等待期自留
153,920 → 扣云服务商 SLA 补偿 280,000 → **实际可赔基数仅 53,391 元，不足事实中断
损失的 11%**。依赖公有云的企业若已获可观 SLA 补偿，从属营业中断责任的边际价值远
低于投保时的直观预期。

**缺口可以来自销售环节（C5）**。阳光 2016 全模块投保时承保面 80%，H公司只投了
模块 1.1 与 1.2：

| | 计入金额 | 赔付额 | 赔付率 |
| --- | ---: | ---: | ---: |
| 仅投 1.1+1.2（本案） | 2,181,501 | 1,920,000 | 37.8% |
| 假设六模块全投保 | 5,076,241 | 4,788,560 | 94.3% |

**投保选择一项造成 2,868,560 元缺口。** 产品理论上能承保，不等于被保险人买到了保障。
模块化设计对销售质量的要求远高于打包式产品。

**程序性条件可能一票否决（C10）**。J单位因情况紧急直接启用长期合作的安全厂商，
未联系保险人指定机构：

| | 赔付额 | 赔付率 |
| --- | ---: | ---: |
| 未联系指定机构（本案） | **0** | 0.0% |
| 假设联系了指定机构 | 490,000 | 21.9% |

**一个流程环节值 49 万元。** 且即便流程走对，仍有 1,469,470 元（占事实损失 65.6%）
因承保面过窄而落空——DDoS 缓解、数据恢复、营业中断、系统升级全在保障范围外。

## 五、引用限制（必读）

**十案全部标注为「尚不可对外引用」。** 审计器对每个案例执行参数来源检查，
当前状态：参数标注覆盖率 100%，但绝大多数为 `editor-estimate`（编者估计）。

| 可信度 | 含义 | 可否引用 |
| --- | --- | :---: |
| `verified` | 可靠来源中的明确数字 | ✓ |
| `derived` | 公开方法与公开输入推算 | ✓ |
| `pending` | 方法已确认，数值待查原始文件 | ✗ |
| `assumed` | 无来源，编者估计 | ✗ |

已核实的部分：**GB/T 42461-2023 表 A.1** 分省市分级别服务人员成本单价，
已用标准公式 (3) `Pᵢ = S × Kᵢ × (1+H)` 逐省复核，31 省市 × 4 级别全部吻合。

待检验的部分：
- **市场加成系数 2.2**（成本 → 实付价格）为假设，且其点估计存在**已披露的循环性问题**
  ——该值是从早期编者估计反推的，「重算后与原估计接近」不构成验证。
  有内容的是区间 1.5–3.0 与「国标成本不含利润」这一结构性事实。
- 工时量、恢复数据量、毛利率、索赔人数、单人赔偿金额等，均按案情设定，
  逐条标注「此参数为假设，待数据检验」。
- 全部分项限额、免赔额、累计限额为演示用假设值——条款原文对这些数值的表述
  普遍为「由投保人与保险人协商确定」，并无公开数字。

**因此：本案例集的赔付率可用于演示条款结构差异与工具能力，不得作为损失金额或
赔付水平的实证依据对外引用。** 引用条款判定（承保 / 除外 / 名义承保）时不受此限，
因其严格依据公开条款文本。
